        Bigfish 版本说明 v0.1.2
   DeepSeek Harness 第三方桌面端
   （非官方，独立社区项目，免费）
══════════════════════════════════════

【这是什么】
Bigfish 是 DeepSeek Harness 的 Electron 桌面版：
把 dsh 本地后端 + 网页界面包进原生窗口，双击即用。

──────────────────────────────
一、v0.1.2 新增了什么（本期核心）
──────────────────────────────

【1. 插件市场】（重大新功能）
   · 托盘图标 → 右键 →「插件市场」
   · 连接社区最大插件平台 awesome-dsh-plugin（1000+ 插件）
   · 支持搜索、分类浏览（桌宠/趣味/效率/界面/开发/记忆/Agent…）
   · 一键安装 / 卸载 / 禁用 / 启用，安装后自动重启生效
   · 装好的插件在 DSH「设置」页里出现自己的设置卡
   · 内置离线插件目录（bundled-plugins，断网也能装）
   · 断网兜底：内置精选目录 plugins.json

【2. 鲸鱼娘桌宠全面升级】
   · 透明悬浮窗重做，动画素材换新（11 种动作分帧动画）
   · 好感度系统：按真实 token 消耗累积好感，升级 Lv.1~10
   · 兑换屋：右键鲸鱼娘打开，把 token 换成 💴 买食物喂她
   · 喂食加好感，等级越高解锁更多互动

【3. 专注模式 / 鲸鱼模式】
   · 首次安装或更新后弹窗选择
   · 🐳 鲸鱼模式：桌宠 + 背景图（默认）
   · 🧘 专注模式：隐藏桌宠、纯色背景，适合专心工作
   · 托盘 → 模式 随时切换

──────────────────────────────
二、稳定性修复
──────────────────────────────
   · 修复插件禁用/启用不生效（市场状态显示错乱）
   · 修复后端启动失败时崩溃，改为引导重置
   · 修复重启后打不开（自动清理残留进程 + 启动重试）
   · 修复桌宠散步不停、窗口尺寸漂移
   · 修复兑换屋「有钱但买不了」问题
   · 更新检查增加 jsdelivr 镜像（国内可访问）

──────────────────────────────
三、安装包
──────────────────────────────
   · Windows：Bigfish Setup 0.1.2.exe（未签名，SmartScreen 点「更多信息→仍要运行」）
   · macOS：Bigfish-0.1.2-arm64.dmg（未签名，右键→打开）
   · Linux：Bigfish-0.1.2.AppImage（chmod +x 后运行） / bigfish_0.1.2_amd64.deb
